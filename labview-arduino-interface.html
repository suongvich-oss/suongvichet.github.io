Project note

LabVIEW-Arduino interface

Serial control as a foundation for experimental systems.

Project overview

This project connects LabVIEW and Arduino through serial communication. The first goal is simple: send a command from a LabVIEW interface and use Arduino to control an output. The bigger goal is to build confidence for future measurement systems where software controls hardware and reads sensor data.

What I practiced

  • Opening and configuring a serial COM port.
  • Sending simple commands from LabVIEW to Arduino.
  • Controlling an Arduino output from a graphical interface.
  • Thinking about how the same idea can support sensor acquisition and actuator control.

Command concept

The first version uses two commands:

  • 1 turns the LED on.
  • 2 turns the LED off.

After this works, the same structure can be expanded to read sensors, control motors, trigger tests, or synchronize an experiment with data recording.

Future improvement

  • Add feedback from Arduino back to LabVIEW.
  • Plot sensor data in real time.
  • Control multiple outputs such as relays, motors, or test fixtures.
  • Use the interface for repeatable mechanical testing and dynamic sensing experiments.
